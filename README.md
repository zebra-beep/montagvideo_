# Скачать Bath Time Fun — 1080×1080

1. Нажмите Code → Download ZIP.
2. Распакуйте архив.
3. На Windows дважды щёлкните Собрать_MP4.cmd — появится готовый Bath_Time_Fun.mp4.

Или выполните вручную в cmd:

copy /b Bath_Time_Fun.mp4.part001+Bath_Time_Fun.mp4.part002 Bath_Time_Fun.mp4

На macOS / Linux выполните в Терминале из папки с частями:

cat Bath_Time_Fun.mp4.part001 Bath_Time_Fun.mp4.part002 > Bath_Time_Fun.mp4
