# Bath Time Fun — mp4

Скачайте ZIP этой ветки через Code → Download ZIP. Распакуйте ZIP и объедините части в один файл.

Windows (cmd):

copy /b Bath_Time_Fun.mp4.part* Bath_Time_Fun.mp4

macOS / Linux:

cat Bath_Time_Fun.mp4.part* > Bath_Time_Fun.mp4

Итоговый файл: 113582803 байт. Частей: 2.
