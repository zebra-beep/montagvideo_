# Bath Time Fun — RGB-мастер без потерь

Скачайте ZIP этой ветки: Code → Download ZIP, распакуйте его.
Внутри мастер разделён на 55 частей по 48 MiB. Для сборки на Windows запустите Собрать_мастер.cmd.

Или выполните в cmd:

copy /b Bath_Time_Fun_MASTER_LOSSLESS.mkv.part* Bath_Time_Fun_MASTER_LOSSLESS.mkv

На macOS / Linux в Терминале:

cat Bath_Time_Fun_MASTER_LOSSLESS.mkv.part* > Bath_Time_Fun_MASTER_LOSSLESS.mkv

Итоговый размер: 2721054294 байта. SHA-256: 1b22c138b21e54c697ae5b24cc54f3b5a9ee2356828dce161af2a3021ce02799

1080×1080, 30 fps, 2:19,77. H.264 RGB CRF 0 без потерь, PCM 24-bit. Можно открыть в VLC.

Ветка создана отдельно от предыдущих проектов. После скачивания её можно удалить.
