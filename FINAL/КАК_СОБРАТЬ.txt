Скачай все 8 файлов vanessa_part00..07.mp4 в одну папку и склей без перекодирования:

  1) Создай файл list.txt с содержимым:
     file 'vanessa_part00.mp4'
     file 'vanessa_part01.mp4'
     file 'vanessa_part02.mp4'
     file 'vanessa_part03.mp4'
     file 'vanessa_part04.mp4'
     file 'vanessa_part05.mp4'
     file 'vanessa_part06.mp4'
     file 'vanessa_part07.mp4'
  2) ffmpeg -f concat -safe 0 -i list.txt -c copy vanessa_final.mp4
